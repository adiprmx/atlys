# Security Policy

## Reporting a vulnerability

Found a security issue in atlys? Please don't open a public issue.

Use **private vulnerability reporting** on this repository
(Security tab → Report a vulnerability), or open a draft security advisory.
Reports are triaged by the maintainer directly.

## Scope

atlys is a collection of agent skills (Markdown + config, no executables).
The most useful reports cover:

- Malicious or unsafe instructions smuggled into a skill
- Supply-chain issues in install commands or referenced tooling
- Anything that could harm users who install these skills

## What to expect

- Acknowledgement of your report
- A fix or mitigation shipped in a patch release
- Credit in the release notes if you'd like it

Thanks for helping keep the collection safe.
